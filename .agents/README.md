## Generated control-plane routes

- `control-plane/source.json` — immutable shared source/interface/generator/adapter pin.
- `control-plane/profile.json` — selected portable profile.
- `control-plane/requirements.json` — requested shared Skill closure.
- `bindings/repository-control-plane.json` — generated content-bound Skill binding.
- `control-plane/bootstrap-receipt.json` — deterministic readback and rollback subject.

Project-local shared Skill bodies are forbidden; consumer adapters remain repository-owned.
