# website-design-compiler

Evidence-first website design compiler for translating references and product briefs into original, accessible, performant, commercially governable web experiences.

This repository consumes shared procedural skills from `ed3c/skills-shared` through explicit bindings. It does not vendor private shared skill bodies into this public repository.
