## Consumer bootstrap State Machine

```text
REPOSITORY_INSPECTED → ROUTES_BOUND → SHARED_SOURCE_BOUND
→ REQUIREMENTS_BOUND → CONSUMER_BINDING_GENERATED
→ RECEIPT_BOUND → VERIFIED
```

Failure terminals: `BLOCKED_MISSING_BINDING`, `BLOCKED_POLICY`, `FAIL`, `HUMAN_ADMIT_REQUIRED`. Documentation cannot create runtime `PASS`.
